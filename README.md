# Testes E2E com Playwright, MCP e GitHub Copilot

<img src="https://octodex.github.com/images/Professortocat_v2.png" align="right" height="200px" />

Olá!

Este é um treinamento de testes end-to-end com
**Playwright**, dirigido por **GitHub Copilot**, com integração via **MCP** e **GitHub Actions**.

Ao criar um repositório a partir deste template, a automação abre uma issue de
acompanhamento e conduz você passo a passo.

## O que você vai praticar

- **Copilot & Skills** — instruções de projeto, agentes e prompts customizados.
- **Playwright + MCP** — gerar testes fundamentados dirigindo o navegador.
- **TDD** — ciclo Red-Green-Refactor em um teste E2E real.
- **GitHub Actions** — CI de E2E com artifacts e workflows reutilizáveis.

## Estrutura

- `src/` — Jogo da Memória (React + Vite).
- `tests/e2e/` — specs do Playwright.
- `playwright.config.js` — configuração do Playwright.
- `.github/` — curso interativo, agentes e prompts do Copilot.
